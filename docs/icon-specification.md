# 图标尺寸规范

## 尺寸定义

| 尺寸 | 像素值 | 使用场景 | 示例 |
|------|--------|----------|------|
| **xs** | 12px | 极小图标、紧凑列表中的操作图标 | 下拉箭头 |
| **sm** | 14px | 小图标、表格操作图标 | 右键菜单项、工具栏小按钮 |
| **md** | 16px | 中等图标、默认图标尺寸 | 按钮、列表项图标、标签页 |
| **lg** | 20px | 大图标 | 输入框前缀、卡片图标 |
| **xl** | 24px | 特大图标 | 页面标题图标、大按钮 |
| **2xl** | 32px | 超大图标 | 空状态图标、头像占位 |
| **3xl** | 48px | 巨型图标 | Hero 区域空状态 |

## 代码约定

```typescript
// Lucide React 图标使用示例
import { ChevronDown, Bot, Send } from 'lucide-react';

// xs - 极小图标
<ChevronDown size={12} />

// sm - 小图标（右键菜单、工具栏）
<ChevronDown size={14} />

// md - 中等图标（默认，最常用）
<Bot size={16} />
<Send size={16} />

// lg - 大图标
<Bot size={20} />

// xl - 特大图标（页面标题）
<Bot size={24} />

// 2xl - 超大图标（空状态）
<Bot size={32} />

// 3xl - 巨型图标
<Bot size={48} />
```

## 组件建议

| 组件类型 | 建议图标尺寸 |
|----------|--------------|
| 按钮（小） | 14px |
| 按钮（中） | 16px |
| 按钮（大） | 20px |
| 列表项图标 | 16px |
| 标签页图标 | 14px |
| 右键菜单项 | 14px |
| 输入框前缀 | 16px |
| 页面标题 | 20px-24px |
| 空状态 | 32px-48px |

## 注意事项

1. **一致性**：同一层级组件使用相同的图标尺寸
2. **可访问性**：最小点击目标 44x44px，图标容器需满足此要求
3. **视觉平衡**：图标与文字大小应匹配
4. **Lucide React**：使用 `size` 属性而非 width/height
